## Architecture Decisions Made

### Type System
- **Canonical types** (new, validated):
  - `Canonical.Floor`, `Wall`, `Room`, `Opening`
  - Used by validation engine, store, comparison
  - Replaces old `FloorPlan` types gradually

### Validation Layer
- **Three-tier approach:**
  1. Real-time (in-editor, deterministic rules)
  2. Rule-based scoring (multi-dimensional rubric)
  3. LLM-hybrid scoring (design iteration, innovation)

### Toast vs Canvas Highlights
- **Toasts chosen over canvas highlights** (pragmatic):
  - Avoids Canvas2D refactor (major work)
  - Validation panel provides detailed feedback
  - Toasts alert users to new critical errors
  - Future: Refactor Canvas2D to Canonical types for full integration
